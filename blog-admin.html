📋 Posts publicados

📤 Exportar a data.json

Genera el JSON listo para reemplazar js/data.json, o publícalo directamente en GitHub con un commit automático.

⚙️ Configuración GitHub

Token con permiso contents:write sobre rgbarco99/rgbarco99.github.io. Se guarda cifrado con tu contraseña de admin en js/admin-config.json y lo comparten todos los paneles y dispositivos.

Se comprueba con GitHub que el token puede escribir en el repo y se publica cifrado. Úsalo cuando el token caduque o lo revoques.

🔑 Cambiar contraseña de admin

Re-cifra el token de GitHub y la clave de los posts privados con la nueva contraseña y publica js/admin-config.json. Se aplica a todos los paneles y dispositivos (tras ~1 minuto de despliegue). Después se cerrará la sesión.
